Visual dream journal for Android

A personal map of recorded dreams

ReverySky applies the same idea of interactive 3D information spaces to dream journaling. Dream notes stay as Markdown files, while the app adds a Star Map, Recall, and light gamification around them.

Free to use / No account required / Notes stored locally as portable Markdown files

Record with context

Store the dream text with a title, tags, importance, recall quality, and structured metadata.

Use Markdown notes

Point the app to a notes folder. Dream entries are stored as .md files compatible with Obsidian-style vault workflows.

Build a visual map

Each recorded dream becomes a Dream Star within a spatial overview of themes, chronology, and recurring images.

Recall older entries

Recall sessions provide a structured way to return to earlier records and refresh details.

Add Buildings

Dream Stars can gain Buildings as the record develops and is revisited.

Collect Boons

Boons add a lightweight progression layer around review activity.

App screens

Gamified visual layer

Progression supports the journal

Recall, Buildings, and Boons give repeated review a visible state. The map records both the original dream and the attention given to it over time.

The core record remains the Markdown note, its metadata, and its place among other entries. The gamified layer organizes review without turning the journal into a separate game loop.
